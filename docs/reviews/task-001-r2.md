## Blockers

1. `.github/workflows/ci.yml:18-21` — `DEVLOOP_ARTIFACTS: ${{ runner.temp }}/devloop` sits in `jobs.gate.env`. GitHub's context table for `jobs.<job_id>.env` allows only `github, needs, strategy, matrix, vars, secrets, inputs`; `runner` is not available there, so the workflow is rejected at parse time or the expression resolves empty. If empty, the gate falls back to `.git/devloop` while the upload step reads `${{ runner.temp }}/devloop/`, so CI evidence is still empty and the round-1 CI blocker is not actually fixed. Required fix: move the `env:` block onto the `Gate (same script as local)` step, where `steps.env` supports `runner`, and keep the upload path; alternatively use a job-env-safe path and upload that same path.
2. `scripts/devloop/common.sh:80-82` and `scripts/devloop/integrate.sh:74-77` — `diff_lines` counts every added and removed line again and returns 428 for `git diff --numstat e70d6a6..HEAD` (365 added, 63 removed), above `MAX_DIFF_LINES=400`. `integrate.sh` will die with `above MAX_DIFF_LINES` unless `--allow-oversized` is passed, and the committed r1 review (48 lines) is already counted while r2 adds more. AGENTS.md section 2.8 says split rather than exceed. Required fix: split the change (for example, move the CI workflow change plus the legacy-store fixture into a follow-up) or, if the human explicitly accepts an oversized task, record that approval in docs/tasks/task-001.md and integrate with `--allow-oversized`.
